# Message Board – Homework 02

## Project Description
A Flutter message board application using Firebase Authentication and Cloud Firestore.

## Features
- User registration and login
- Splash screen and authentication state checking
- Firestore user records with five required fields
- Create, read, edit, and delete messages
- Real-time message updates
- Firestore security rules

## Technologies
- Flutter and Dart
- Firebase Authentication
- Cloud Firestore

## Testing
The application was tested for registration, login, message operations, and Firestore data storage. Additional security and release APK tests should be documented with the actual results in the evidence report.
